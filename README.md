# 🚀 Projeto de Consolidação - Design Profissional

Este repositório foi criado para a aplicação prática dos conceitos aprendidos na trilha **GitHub Foundations** (Microsoft Learn), como parte da disciplina de Design Profissional.

- Implementar fluxo de trabalho com branches, commits e Pull Requests.
- Consolidar a construção da identidade e imagem profissional técnica.

## 🛠️ Tecnologias e Ferramentas
- Git & GitHub
- Markdown
- Microsoft Learn (Trilha GitHub Foundations)
